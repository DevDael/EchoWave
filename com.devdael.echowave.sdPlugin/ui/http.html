What do HTTP 200, 404 and 503 mean?

An HTTP number means the server answered. It does not prove that the page or service works as intended.

Status groups

2xx
The request succeeded.
3xx
Redirect or cache response. EchoWave does not follow redirects.
4xx
The server rejected the request or resource.
5xx
The server or gateway could not complete the request.

Common codes

200
OK: the GET request succeeded.
204
Success, with no response body.
301 / 302
Permanent / temporary redirect.
400
Bad request.
401 / 403
Authentication required / access forbidden.
404
The requested URL path was not found.
429
Too many requests; rate limited.
500
Internal server error.
502 / 504
Bad gateway response / gateway timeout.
503
Service temporarily unavailable.

TIMEOUT, DNS ERROR and TLS ERROR are not HTTP codes: no HTTP response was received. HTTP 404 or 503 means a server did reply.
