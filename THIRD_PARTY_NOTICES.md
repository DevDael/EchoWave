# Third-party visual credit

## Hexaza

The Hexaza background and visual identity are by [Piotezaza](https://marketplace.elgato.com/@piotezaza). The free Marketplace plugin's ping and web themes combine the approved background with EchoWave's own status text and pulse animation. This source repository contains the theme code but does not publish Piotezaza's original PNG as a standalone file.

Piotezaza permitted its inclusion in EchoWave provided the plugin is available free of charge and Piotezaza is credited. This permission was given in a Discord reply shared with the project owner on 2026-09-27; the screenshot is retained privately as evidence. Hexaza remains Piotezaza's work and is **not** covered by the MIT license for EchoWave's original code. No permission for a paid version or independent redistribution of the original Hexaza artwork is asserted here.

Hexaza is credited when selected in either action's Property Inspector. The Marketplace listing should carry this credit as well.
